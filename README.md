# 🏴‍☠️ Pirate Radar

**A pirate-style radar overlay for treasure-hunt events, stream shows and pranks.**

> ⚠️ **This is a decorative prop. It does not track, read or detect anything in any game.**
> The coin on the radar is scripted for show and never leads to a real location. Use it as an entertainment element for your event.

## What it is

Pirate Radar is a small Windows app that puts a themed sonar radar in the corner of your screen, on top of your game window. It is built for event hosts, streamers, Discord communities and friends who want a dramatic "treasure hunt" prop: a sweeping sonar, pings, a drifting golden blip, fake "hot" moments and a dramatic signal-lost finale.

## Features

- Animated sonar sweep with sound, pings get faster and higher when the signal is "hot"
- Scripted fake "hot" moments: the blip rushes toward the center, the radar turns red and shakes, then the signal slips away
- Decoy blips and random interference for extra tension
- Pirate-captain phrases and playful hint messages that lead nowhere
- Random 2-5 minute timer, then a static-filled "SIGNAL LOST" finale
- Old brass compass look with a faint treasure-map background
- Always-on-top, click-through overlay in the top-right corner
- Tray icon with quick controls and Quit
- English interface

## How it works

1. Launch Pirate Radar. It waits in the system tray.
2. When your event round starts, press **F8**.
3. The radar shows a drifting coin signal. After a random 2-5 minutes it fades out with a signal-lost effect.
4. Press **F8** again to start a new round.

The overlay appears automatically while Fortnite is running (it only checks whether the game process exists). You can also show or hide it manually with **F9**.

## Hotkeys

| Key | Action |
|-----|--------|
| F8 | Start a hunt (random 2-5 min) |
| F7 | 10-second test run |
| F9 | Show / hide the radar |

## Requirements

- Windows 10 or 11
- The game must run in **Windowed Fullscreen** (borderless) mode, otherwise overlays cannot be displayed on top of it

## FAQ

**Does it find the coin in the game?**
No. It is a prop. The signal is scripted and never points to a real location.

**Will it get me banned?**
It does not inject into, read from or modify the game, its files or its memory. It is a separate window that sits on top of the screen and only checks whether the game process is running.

**Why does Windows show an "unknown publisher" warning?**
The installer is not code-signed. Choose "More info" and then "Run anyway" if you trust the source.

**Can I use it outside Fortnite?**
Yes. It works as an overlay on top of any game or app running in windowed or borderless mode.
